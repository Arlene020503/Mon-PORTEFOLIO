MonLogement
Location immobilière en Côte d'Ivoire — Web & Mobile

Web · Mobile · IA

Plateforme de location de logements pensée pour lutter contre les arnaques et les frais de visite élevés. Les locataires trouvent un logement et contactent directement le propriétaire ; les propriétaires publient et gèrent leurs annonces. Une seule base de code Flutter pour la version web et l'application Android.

  • Flutter
  • Flask
  • MySQL (TiDB Cloud)
  • Machine Learning
  • Agent IA (Groq)

Fonctions : recherche et filtres, estimation du prix par ML, agent IA conversationnel (conseils de quartiers), favoris, questionnaire de préférences, publication d'annonces avec photos, contact WhatsApp / email, signalement, tableau de bord propriétaire, mode sombre, FR / EN.
